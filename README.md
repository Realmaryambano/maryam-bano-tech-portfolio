## ✨ About

This portfolio represents the **technical side** of Maryam Bano — a Computer Science undergrad at Bahria University, Karachi, and a self-taught full-stack developer with hands-on experience across AI/ML, web development, and enterprise systems.

It's built as a single, animated React component: custom cursor, scroll-triggered reveals, a live theme toggle (light/dark), animated stat counters, tilt-on-hover project cards, and a scrollable certifications timeline — all without any external UI framework.

## 🛠️ Tech Stack

- **Framework:** React (functional components + hooks)
- **Icons:** [lucide-react](https://lucide.dev/), [react-icons](https://react-icons.github.io/react-icons/) (`FaGithub`, `FaLinkedin`, `FaYoutube`)
- **Styling:** Custom CSS-in-JS (no Tailwind/UI library) — CSS variables for theming, `color-mix()` for accent shading
- **Fonts:** [Fraunces](https://fonts.google.com/specimen/Fraunces), [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- **Animation:** `IntersectionObserver`-driven scroll reveals, CSS keyframes, mouse-tilt project cards
- **Hosting:** [Vercel](https://vercel.com/)

## 📦 Getting Started

```bash
# clone the repo
git clone https://github.com/Realmaryambano/<repo-name>.git
cd <repo-name>

# install dependencies
npm install

# run locally
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

### Adding your own images

Drop your images into `/public/images/` matching the filenames referenced in the `IMAGES` and `PROJECTS` objects at the top of the component — no other code changes needed.

### Adding your resume

Place `Maryam_Bano_Resume.pdf` in the `/public` folder (or update `RESUME_HREF` to point to a hosted link).
